# Security policy

Report suspected vulnerabilities privately to the contact in https://complyable-one.vercel.app/.well-known/security.txt. Include the affected URL and steps to reproduce. We aim to acknowledge within 3 business days. Please do not open public issues for security reports.

Policy and safe-harbor terms: https://complyable-one.vercel.app/security#vulnerability-disclosure
This repository contains only the CI client. Secrets passed to it (API key, cookies, headers) are masked in workflow logs and sent only to the ComplyAble API.
